# Cart App 🛒

This is a FastAPI-based shopping cart application with API endpoints to add, remove, and view items in a cart. It uses SQLAlchemy and Alembic for database and migration handling.

## 🔧 Features

- Add items to the cart
- Remove items from the cart
- View cart contents
- SQLite database with Alembic migrations

## 🚀 Tech Stack

- Python 3
- FastAPI
- SQLAlchemy
- Alembic
- SQLite
